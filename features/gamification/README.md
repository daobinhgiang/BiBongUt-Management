# gamification

Gamification — XP, levels, streaks, badges, quests, leaderboard, family level, and titles. Core engagement system that rewards participation across all features.

## Structure

```
gamification/
  hooks/        # React hooks (data fetching, mutations, local state)
  components/   # UI components specific to this feature
  xp/           # Experience points system
  levels/       # Level progression
  streaks/      # Activity streaks
  badges/       # Achievement badges
  quests/       # Daily/weekly quests
  leaderboard/  # Family leaderboard
  familyLevel/  # Collective family level
  titles/       # User titles and ranks
  types.ts      # TypeScript type definitions
  index.ts      # Barrel export
```

## Status

Scaffolded — no business logic implemented yet.
