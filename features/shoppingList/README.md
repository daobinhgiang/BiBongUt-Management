# shoppingList

Shopping List — collaborative grocery and household shopping lists. Items can be added, checked off, and categorized by store section.

## Structure

```
shoppingList/
  hooks/        # React hooks (data fetching, mutations, local state)
  components/   # UI components specific to this feature
  types.ts      # TypeScript type definitions
  index.ts      # Barrel export
```
