# pantry

Pantry — household pantry inventory tracking. Monitors stock levels, expiration dates, and auto-suggests items for the shopping list.

## Structure

```
pantry/
  hooks/        # React hooks (data fetching, mutations, local state)
  components/   # UI components specific to this feature
  types.ts      # TypeScript type definitions
  index.ts      # Barrel export
```

## Status

Scaffolded — no business logic implemented yet.
