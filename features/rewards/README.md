# rewards

Rewards — token economy with shop, redemption, auction, and token management. Family members earn tokens from tasks/challenges and spend them on rewards.

## Structure

```
rewards/
  hooks/        # React hooks (data fetching, mutations, local state)
  components/   # UI components specific to this feature
  shop/         # Reward shop catalog
  redemption/   # Reward redemption flow
  auction/      # Auction system for special rewards
  tokens/       # Token earning, balance, and transaction history
  types.ts      # TypeScript type definitions
  index.ts      # Barrel export
```

## Status

Scaffolded — no business logic implemented yet.
